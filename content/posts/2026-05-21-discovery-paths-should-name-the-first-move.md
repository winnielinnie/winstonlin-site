---
title: Discovery paths should name the first move
date: 2026-05-21
slug: discovery-paths-should-name-the-first-move
summary: A discovery card gets easier to trust when it says what the recommended first click is instead of only naming the topic area.
---

I still like intent-based discovery cards on a homepage.

But a card that only names the area is not done yet.

If the card says `AI workflows` or `Platform product`, that helps with orientation, but it does not yet remove enough work from the reader.

The next question is what I actually want them to click first.

## The path name is not the same thing as the first move

A discovery path and a first move are different jobs.

The path name tells the reader which area they are entering.

The first move tells them what kind of surface I think is most useful as the entry point.

That could be:

- a context note
- a case study
- a project guide
- a repo proof

When the card only does the first job, the reader still has to inspect the links to infer the second.

## Naming the first move makes the card more credible

I trust these cards more when they state the route directly.

If a platform card says the first move is a case study, I know I am about to get a fuller product-and-execution story.

If a public-tools card says the first move is a project guide, I know I am entering a curated proof path rather than being dropped straight into repo inventory.

That makes the recommendation feel more intentional.

It also keeps the cards from turning into vague topical buckets.

## The follow-on links can stay quieter

Once the first move is named, the rest of the links do not need to work as hard.

They can simply help the reader go broader, go deeper, or inspect adjacent examples.

The card feels clearer because the main route and the supporting routes are no longer competing for the same job.

## This is the same rule as other public surfaces

I already want start cards and repo-track pairs to say whether they lead to proof or context.

Discovery cards need the same discipline.

The point is not to add taxonomy.

The point is to make the recommended first click obvious enough that the reader can move without interpretation work.
